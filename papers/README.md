# Paper corpus

The PDFs are not committed — they belong to their authors. Download them into
this directory and run `python pdf_to_text.py` to build `data/papers.txt`.

```bash
curl -L -o 1706.03762.pdf https://arxiv.org/pdf/1706.03762
```
